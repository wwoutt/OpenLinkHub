# wwoutt/OpenLinkHub: XENEON EDGE extensions

This repository is a **fork** of [OpenLinkHub](https://github.com/jurkovic-nikola/OpenLinkHub)
by **[Nikola Jurković (jurkovic-nikola)](https://github.com/jurkovic-nikola)**.
OpenLinkHub is his open-source Linux interface for Corsair devices; all
credit for OpenLinkHub itself (device support, the web UI, the XENEON EDGE
kiosk page and its widgets) goes to him and the upstream contributors.
If you like OpenLinkHub, support and star the [original project](https://github.com/jurkovic-nikola/OpenLinkHub).

This fork adds extras for the **Corsair XENEON EDGE** touchscreen on top of
that work. Everything else is unchanged upstream code.

## What it is
- **XENEON EDGE kiosk**: the OpenLinkHub kiosk page opens fullscreen on the
  XENEON EDGE only, and starts automatically when you log in. The touchscreen is
  mapped to the XENEON EDGE, so touches land on the right screen
  ([extras/xeneon-kiosk](extras/xeneon-kiosk/README.md)).
- **Free layout**: drag, resize, hide and configure the widgets on the XENEON
  EDGE, on the touchscreen itself or in the browser via the new
  **XENEON EDGE layout** entry in the OpenLinkHub sidebar. The XENEON EDGE follows
  changes made in the browser within seconds
  ([extras/xeneon-layout](extras/xeneon-layout/README.md)).
- **Custom widgets**: make your own widgets with plain HTML, with data from the
  internet (a URL) or from Linux (a script)
  ([how to make a widget](extras/widget-helper/README.md),
  [AI prompt to generate one](extras/widget-helper/AI-WIDGET-PROMPT.md)).
- **Widget store**: install widgets from the reviewed catalog
  [wwoutt/openlinkhub-widgets](https://github.com/wwoutt/openlinkhub-widgets)
  or from community repositories on GitHub with the topic
  [`openlinkhub-widget`](https://github.com/topics/openlinkhub-widget).
- **Build and deploy scripts** for immutable distributions such as Bazzite and
  Fedora Atomic, where `/usr` is read-only
  ([build and deploy](extras/xeneon-layout/README.md#build-and-deploy)).

## Tested on
- Bazzite 44 (Fedora Atomic), KDE Plasma 6 on Wayland

- OpenLinkHub 0.9.4

## Install
1. Install OpenLinkHub from this fork as described in the upstream
   [README](README.md#installation-recommended), or build it in a container with
   `extras/build-podman.sh` and copy it with `extras/deploy-local.sh`
   (see [build and deploy](extras/xeneon-layout/README.md#build-and-deploy)).
2. Kiosk: `extras/xeneon-kiosk/install.sh`
3. Custom widgets and the store: `extras/widget-helper/install.sh`
4. Open `http://127.0.0.1:27003/` and click **XENEON EDGE layout** in the sidebar.

## Changes to upstream code
All fork functionality lives in new files. Upstream files only get small hooks
so that upstream updates merge easily:

| Upstream file | Change |
|---|---|
| `README.md` | one line at the top pointing to this page, and the fork section at the bottom |
| `src/server/server.go` | an import and one call to `xeneonlayout.RegisterRoutes(r)` at the end of `setRoutes()` |
| `web/xeneon.html` | one `<script>` line loading `static/js/xeneon-layout.js` |
| `web/sidebar.html` | one `{{ template "sidebar-xeneon-layout" . }}` line for the sidebar link |

After merging an upstream update, `extras/check-hooks.sh` checks that these hooks
are still present.
